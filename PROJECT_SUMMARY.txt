PROJECT OVERVIEW
----------------
A production-ready agentic AI system with advanced reasoning, multi-layer
memory, code execution, and OSINT capabilities. Deployable on Render.com.

----------
Total Python files:     11

ARCHITECTURE COMPONENTS
-----------------------

1. DISCORD BOT INTERFACE (src/discord/)
   - Multi-server deployment capability
   - Slash commands: /ask, /reason, /memory, /upload, /osint, /help
   - Natural language processing (mentions & DMs)
   - Role-based access control (Admin-only OSINT)
   - File processing: ZIP repository analysis
   - Thread and channel context awareness
   - User-specific memory recall

2. MULTI-LAYER MEMORY (src/memory/)
   - Layer 1: Working Memory (current conversation)
   - Layer 2: Episodic Memory (conversation history)
   - Layer 3: Semantic Memory (learned concepts)
   - Layer 4: Procedural Memory (skills & strategies)
   - Graph Database: Entity relationships (NetworkX)
   - Vector Store: Semantic search (ChromaDB + sentence-transformers)
   - Sleep-Time Compute: Background relationship building
   - Decay & Scoring: Dynamic relevance weighting
   - Entity Disambiguation: "Which Max in Singapore?"

3. ADVANCED REASONING (src/reasoning/)
   - Sequential: Chain-of-Thought reasoning
   - Parallel: Tree-of-Thoughts (multi-path exploration)
   - Reflective: Self-critique and refinement loops
   - Analogical: Cross-domain pattern matching
   - Code Sandbox: Restricted Python execution
   - Tool Registry: Dynamic function calling

4. OSINT MODULE (src/osint/)
   - Admin-only activation (explicit user request)
   - User Intelligence: metadata, activity patterns, linked accounts
   - Server Intelligence: structure, roles, invites
   - Message Analysis: temporal patterns, content analysis
   - Social Graph: NetworkX relationship mapping
   - Structured Reports: Markdown/JSON export

5. LLM CLIENT (src/utils/llm_client.py)
   - Primary: Cerebras API with gpt-oss-120b
   - Automatic key rotation on rate limits
   - Fallback: OpenAI, Anthropic (if configured)
   - Exponential backoff with jitter
   - Request tracking and monitoring

6. PERSONALITY SYSTEM (src/personality/)
   - Few-shot prompting architecture
   - System Prompt -> Dialogue Examples -> Memory -> Current
   - Configurable traits and communication rules
   - Error handling templates

DEPLOYMENT
----------
Platform:     Render.com
Services:     Web (bot) + Redis + Worker (background)
Storage:      Persistent disk (10GB)
Runtime:      Python 3.11+

KEY FEATURES
------------
✓ Memory-First Design: Reasoning IS Memory
✓ Sleep-Time Compute: Background processing
✓ Human On the Loop: Autonomous with supervision
✓ Self-Repair: Context accumulation over time
✓ Skill Building: Procedural memory from patterns
✓ Multi-Server: Deploy across multiple Discord servers
✓ Rate Limit Protection: API key rotation
✓ Security: Role-based access, sandboxed execution
